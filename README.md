# كول سنتر — تسجيل العملاء (PWA)

أبسط تطبيق ويب للكول سنتر لتسجيل بيانات العملاء واستهداف المحتملين لاحقًا، مع تصدير Excel/CSV.

## المميزات

- تسجيل: الاسم، الرقم، الاهتمام، الحجز، اليوم، الوقت، الخدمة، الموظف، التفاصيل
- فلترة وبحث سريع للاستهداف
- إحصاءات مباشرة (إجمالي / مهتمين / محتملين / محجوز)
- تصدير **Excel** بجداول: كل العملاء + ملخص + المحتملين + المحجوزين
- تصدير **CSV** يفتح مباشرة في Google Sheets / Excel
- يعمل كتطبيق (PWA) ويمكن تثبيته على الجهاز
- البيانات تُحفظ محليًا في المتصفح (Local Storage)

## التشغيل

1. افتح المجلد في VS Code / Cursor
2. شغّل Live Server، أو من الطرفية:

```bash
npx --yes serve .
```

3. افتح الرابط في المتصفح (يفضّل Chrome)

> ملاحظة: تثبيت الـ PWA يحتاج فتح التطبيق عبر `http://localhost` أو HTTPS.

## الاستخدام السريع

1. املأ بيانات المكالمة واضغط **حفظ العميل**
2. استخدم الفلاتر لإظهار المهتمين أو المحتملين
3. اختر نطاق التصدير ثم اضغط **تصدير Excel**
